# LaTeX 论文格式规范

## 唯一权威来源

论文结构、文档类、页面、摘要页、编号、字体、页数和提交文件必须遵循目标竞赛当届官方规则与官方 LaTeX 模板。内置模板只在没有官方模板时提供构建基线。

## 模板驱动生成

1. 将官方模板项目完整复制到 `PROJECT_ROOT/完整论文-LaTeX/`，保留 `.tex`、`.cls`、`.sty`、`.bst`、`.bib`、字体和模板图片。
2. 确认主入口文件；模板有多个顶层候选 `.tex` 时，不猜测，按官方说明通过 `--main` 显式选择。
3. 只编辑复制件中的正文与明确占位位置，不重写官方导言区、文档类和固定页。
4. 把编程手的真实图表和核验后的参考文献放入项目，使用项目内相对路径。
5. 由官方模板决定编译引擎和参考文献后端；未指定时，中文基线使用 XeLaTeX。

详细命令与校验能力见 `../../../../tools/latex/SKILL.md`。

## 公式、图表和引用

- 公式保留为原生 LaTeX，并在实际编译 PDF 中检查换行、编号和字体。
- 每幅图和每个表都有题注与 `label`，正文至少一次使用 `ref`、`autoref` 或同类命令引用。
- 图只使用编程手真实生成的文件；不依赖 shell escape 临时转换 SVG。
- 正文 `cite` 键必须能在 `.bib` 或 `bibitem` 中找到；手工参考文献不得成为未引用条目。

## 编译与校验

优先使用 `latexmk` 完成交叉引用与参考文献构建，不启用 shell escape，也不读取项目级 `.latexmkrc`。未安装 `latexmk` 时，仅允许没有外部 BibTeX/BibLaTeX 文献库的项目回退为两次引擎编译。缺少 TeX 引擎、参考文献后端或宏包时明确报告环境问题，不自动联网安装或静默换引擎。

交付前必须同时满足：

- 源码不含模板占位符、越界文件引用或被禁用的文件/命令执行指令；
- 实际编译成功，日志无未解析引用和文献；
- 篇幅、公式、图、表、图文关联与参考文献对应检查通过；
- 以编译 PDF 的实际页数核对官方上限和内部完整度目标；
- 打开 PDF 抽检摘要页、分页、页眉页脚、字体、公式、表格、图片和参考文献。

## 交付

交付完整源码项目 `PROJECT_ROOT/完整论文-LaTeX/`，以及由该项目实际编译得到的 `PROJECT_ROOT/完整论文.pdf`。不要只交一个脱离 `.cls/.sty/.bib` 依赖的 `.tex` 文件。
