# 论文格式规范

本规范来自默认模板 `references/roles/论文手/references/论文模板.docx` 的实际样式分析。生成论文时以本文件为准，`tools/docx/scripts/paper_format.py` 已内置这些基础格式。

## 页面设置

| 项目 | 设置 |
|------|------|
| 纸张 | A4，21 cm × 29.7 cm |
| 上边距 | 2.54 cm |
| 下边距 | 2.54 cm |
| 左边距 | 3.18 cm |
| 右边距 | 3.18 cm |
| 页眉页脚 | 默认，不额外设置特殊格式 |

## 基础字体

| 内容 | 格式 |
|------|------|
| 中文正文 | 宋体，小四，12 pt |
| 英文与数字 | Times New Roman，12 pt |
| 正文段落 | 首行缩进 2 字符，1.25 倍行距，段前段后 0 |

## 标题与正文

| 部分 | 字体 | 字号 | 加粗 | 对齐 | 其他 |
|------|------|------|------|------|------|
| 论文标题 | 黑体 | 14 pt | 否 | 居中 | 无首行缩进 |
| 摘要标题 | 黑体 | 14 pt | 否 | 居中 | 固定写作 `摘 要` |
| 摘要正文 | 宋体 | 12 pt | 否 | 左对齐 | 首行缩进 2 字符 |
| 关键词 | 宋体 | 12 pt | 标签加粗 | 左对齐 | 与摘要正文之间空一行；`关键词：`加粗，内容不加粗 |
| 一级标题 | 宋体 | 16 pt | 是 | 居中 | 每章另起一页；如 `一、问题重述` |
| 二级标题 | 宋体 | 14 pt | 否 | 左对齐 | 如 `1.1 问题背景` |
| 三级标题 | 宋体 | 12 pt | 是 | 两端对齐 | 如 `问题一的建立`、`问题一的求解` |
| 正文 | 宋体 | 12 pt | 否 | 左对齐 | 首行缩进 2 字符 |
| 参考文献标题 | 宋体 | 16 pt | 是 | 居中 | 按一级标题处理 |
| 附录标题 | 宋体 | 16 pt | 是 | 左对齐 | 用户模板若要求居中则按模板 |

## 三线表

三线表必须使用 Word 表格边框实现，不允许截图。

| 项目 | 设置 |
|------|------|
| 表格结构 | 顶线、表头下横线、底线 |
| 竖线 | 无 |
| 左右边框 | 无 |
| 表头 | 宋体 12 pt，加粗，居中 |
| 内容 | 宋体 12 pt，居中 |
| 推荐工具 | `tools/docx/scripts/paper_format.py` 的 `three_line_table()` |

## 公式

LaTeX 只负责表达数学公式，不负责整篇论文排版。

生成 Word 论文时，用 `paper_format.py` 的 `equation()` 将 LaTeX 公式直接写成 Word 原生公式 OMML。已有 `.docx` 占位符文档可用 `tools/docx/scripts/equations.py replace` 替换。最终 `.docx` 中的公式必须能在 Word 中编辑，不能是纯文本 LaTeX，也不能是截图。

示例：

```python
from tools.docx.scripts import paper_format as pf

doc = pf.new_document()
pf.equation(doc, r"\min f(x)=\sum_{i=1}^{n}x_i^2")
doc.save("论文.docx")
```

占位符替换示例：

```bash
python tools/docx/scripts/equations.py replace 论文.docx ^
  --replace "EQ_OBJECTIVE" "\\min f(x)=\\sum_{i=1}^{n}x_i^2" ^
  -o 论文_final.docx
```

## 交付前检查

生成或修改论文后至少运行：
