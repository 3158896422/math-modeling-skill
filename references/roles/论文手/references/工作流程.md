# 论文手工作流程

## 执行前检查

1. 读取 `references/roles/论文手/references/论文格式规范.md`，确认格式要求。
2. 运行环境检查：

```bash
python tools/docx/scripts/check_env.py
```

3. 生成 Word 论文时优先使用 `tools/docx/scripts/paper_format.py`。
4. LaTeX 只用于公式，最终用 `tools/docx/scripts/equations.py` 转为 Word 原生公式。

## 五步流程

### 1. 收集资料

收集题目、建模手分析、编程手代码与结果、图表、参考文献、用户模板或默认模板。缺失的内容必须标注，不得补造数据或文献。

### 2. 构建论证

先写一句话论证，再写正文：

```text
针对 [问题]，本文采用 [方法/模型] 实现 [结果]，
通过 [证据] 支撑，适用范围为 [边界条件]。
```

同步建立 Claim-Evidence 映射：

| 主张 | 证据 | 位置 | 状态 |
|------|------|------|------|
| 模型有效 | 表 1 / 图 2 / 指标结果 | 第 5 章 | 已支撑 |
| 模型可推广 | 暂无证据 | 第 7 章 | 待补充或弱化 |

### 3. 撰写正文

按 `章节模板.md` 写章节，按 `写作规范.md` 控制语气。每个关键结论必须紧跟证据；没有证据时使用 `[待补充：...]` 占位符或弱化表述。

### 4. 生成 Word

使用 `paper_format.py` 统一生成页面、标题、正文、关键词、三线表等格式。

```python
from tools.docx.scripts import paper_format as pf

doc = pf.new_document()
pf.title(doc, "论文题目")
pf.abstract_title(doc)
pf.body(doc, "摘要正文。")
pf.keywords(doc, "优化；预测；评价")
pf.heading1(doc, "一、问题重述")
pf.three_line_table(doc, [["符号", "说明", "单位"], ["x", "决策变量", "-"]])
doc.save("论文.docx")
```

公式处理采用占位符：

```bash
python tools/docx/scripts/equations.py replace 论文.docx ^
  --replace "EQ_OBJECTIVE" "\\min f(x)=\\sum_{i=1}^{n}x_i^2" ^
  -o 论文_final.docx
```

### 5. 交付前检查

```bash
python tools/docx/scripts/self_check.py
python tools/docx/scripts/office/validate.py 论文_final.docx
```

同时核对：

| 项目 | 要求 |
|------|------|
| 三线表 | 只有顶线、表头下横线、底线，无竖线 |
| 公式 | Word 原生公式，不能是 LaTeX 纯文本或截图 |
| 引用 | 正文 `[n]` 与参考文献列表一一对应 |
| 缺失输入 | 全部用 `[待补充：...]` 标明 |

## 输出清单

交付时包含：

1. `论文.docx` 或 `论文_final.docx`
2. 假设与缺失输入列表
3. Claim-Evidence 映射表
4. 参考文献核对结果
5. 结构说明，说明为什么这样组织章节
