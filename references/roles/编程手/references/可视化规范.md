# 可视化规范

本规范把 Nature Skills 的“图是可审查的视觉论证”和 SciPilot 的“先理解数据、再选图、最后回看成图”融入数学建模流程。默认采用克制、清晰、可编辑的 Nature/SCI 风格基线，但这不代表通过任何期刊的官方格式认证；目标竞赛、学校或期刊的当届规范始终优先。

## 三类图与候选策略

1. 原始数据图：分布、时间趋势、空间结构、相关性和异常点。
2. 模型运行过程图：收敛、训练、残差、灵敏度、消融和约束状态。
3. 模型最终结果图：方案、预测、排名、误差和不确定性。

三类都要覆盖，文件名前缀分别使用 `raw_`、`process_`、`result_`。候选图多多益善，不设置最多图数；允许同一数据从不同有效视角生成备选图，由论文手和用户按叙事需要选择。最终进入论文的每张图仍须说明它支撑的结论。

## 绘图前门禁

### 1. 数据剖析

先核对实际读取结果，再决定图型：

- 文件、工作表、表头约定、首行、末行和总行数；
- 每列的数据类型、单位、缺失率、唯一值和数值范围；
- 各分组样本量、分布形态、异常值与重复测量结构；
- 变量相关性、时间/空间顺序和模型输出的统计定义；
- 任何删行、聚合、抽样或异常值处理的前后数量、规则与理由。

不得为了套模板或加快绘图静默删数据。点数过多时可使用透明度、hexbin、密度图或有明确规则的聚合，并保留原始数据图。

### 2. 图表契约

写代码前，在工作记录或代码注释中明确：

```text
核心结论：这张候选图希望读者看出什么？
所属类别：raw / process / result
证据映射：每个面板分别使用什么数据、回答什么问题？
图型与理由：为什么这种视觉编码适合当前变量和结论？
统计要求：n、中心统计量、离散程度/区间、检验与校正是什么？
输出要求：最终宽高、语言、SVG/PNG、目标模板中的预计尺寸是什么？
风险检查：是否可能误导尺度、遮挡数据、缺字或混淆颜色？
源数据追溯：输入文件、工作表/字段、过滤或聚合前后数量是什么？
```

信息不足时先从题目分析报告和数据推断，明确记录假设；会改变结论或统计口径时再询问用户。无法判断图型时读取 [图表选择与避坑.md](图表选择与避坑.md)。

## 出版级样式基线

- 默认白色背景、无网格线、无装饰性渐变和立体效果；普通数据图隐藏上、右边框。
- 图宽按论文中的最终尺寸设置，避免在 Word/LaTeX 中大幅二次缩放。内置 `report` 宽度为 6.3 in，`single`/`double` 仅作为常见单栏/双栏起点；官方模板有规定时覆盖它们。
- 最终尺寸下正文标签通常使用 7–9 pt，任何文字不得小于 6 pt；同一组图的字体、字号和线宽保持一致。
- 同一方法、变量或方案跨图保持相同颜色语义。优先使用色觉友好配色，并以线型、标记或纹理提供冗余编码。
- 连续单向数值使用感知均匀色图，如 `viridis`、`magma`、`cividis`；以零为中心的正负数据使用带明确中心值的发散色图。禁止 `rainbow`、`jet` 等会制造虚假视觉梯度的色图。
- 坐标轴必须写变量名和单位；连续颜色映射必须有带单位的 colorbar。柱状图通常从零开始；需要截断或对数轴时必须有统计/物理理由并显式标注。
- 图例不得遮挡数据。多面板图共享颜色语义和尺度；面板编号统一使用 `a`、`b`……小写粗体。
- 误差棒、阴影区间和箱线图必须在图注说明样本量、中心统计量、SD/SEM/CI/IQR、检验方法及多重比较校正。
- 统计量、置信区间和 p 值必须由代码从当前数据计算，禁止硬编码；置信区间不能用标准差冒充。
- 数据图同时保存带可编辑文本的 SVG 和至少 300 DPI 的 PNG，不要只调用 `show()`，也不要用截图或 JPEG 代替正式导出。

## 复用现有代码或模板

- 先判断是完整复用、结构复用、仅继承样式，还是应该重新实现；不能因为示例能运行就认定适配当前数据。
- 写清“模板字段 → 当前字段 → 统计角色 → 单位”的映射，不得静默选择方便的列或改变类别顺序。
- 对数、比值、归一化、开方、分箱、相关性、PCA 和聚类都要重新检查输入条件；条件不满足时不能只为画出相似图而修改统计含义。
- 默认使用全部有效观测。确需过滤、聚合或抽样时，记录规则、前后数量、随机种子及其对结论的影响。
- 示例数据和模拟数据不得混入正式结果；先把模板复制到 `PROJECT_ROOT` 再修改，保持 `SKILL_ROOT` 只读。


## 两个子图示例（Python）

```python
import matplotlib.pyplot as plt
from utils.plot_style import PALETTE, apply_publication_style, export_figure

apply_publication_style(language="zh", width="report")
fig, axes = plt.subplots(1, 2, constrained_layout=True)
axes[0].plot(x, raw_values, color=PALETTE["primary"])
axes[0].set(title="原始数据", xlabel="时间（s）", ylabel="观测值（单位）")
axes[1].plot(x, predicted, color=PALETTE["contrast"], label="预测")
axes[1].fill_between(
    x, lower_ci, upper_ci,
    color=PALETTE["contrast"], alpha=0.16, label="95% CI",
)
axes[1].set(title="预测结果", xlabel="时间（s）", ylabel="预测值（单位）")
axes[1].legend()
export_figure(fig, PROJECT_ROOT / "figures" / "result_prediction")
plt.close(fig)
```

`export_figure()` 默认先检查缺字、画布外文字和刻度重叠，再按固定物理尺寸导出；同时把灰度预览写入 `figures/_qa/`。不要使用 `bbox_inches="tight"` 代替布局修复，它会改变图表契约中的最终宽高。

## 两个子图示例（MATLAB）

```matlab
fig = figure;
style = apply_publication_style(fig, "zh", "report");
layout = tiledlayout(fig, 1, 2, "TileSpacing", "compact", "Padding", "compact");

nexttile;
plot(x, rawValues, "Color", style.colors(1,:), "LineWidth", 1.4);
xlabel("时间（s）"); ylabel("观测值（单位）"); title("原始数据");

nexttile;
hold on;
fill([x; flipud(x)], [lowerCI; flipud(upperCI)], style.colors(4,:), ...
    "FaceAlpha", 0.16, "EdgeColor", "none");
plot(x, predicted, "Color", style.colors(4,:), "LineWidth", 1.4);
xlabel("时间（s）"); ylabel("预测值（单位）"); title("预测结果");
hold off;

export_publication_figure(fig, fullfile(PROJECT_ROOT, "figures", "result_prediction"));
close(fig);
```

不要调用 `grid on`。某个特殊图确需参考线时，只画有明确数值意义的阈值线、零线或基准线，并在图注解释。

## 导出后的自检闭环

1. 运行项目代码，生成 SVG 与 PNG。
2. 用内置审计器检查三类前缀、格式配对、PNG DPI、实际物理尺寸元数据和 SVG 可编辑文本：

   ```powershell
   python "<ROLE_ROOT>/scripts/figure_audit.py" "<PROJECT_ROOT>/figures" --strict
   ```

3. 实际打开每张 PNG 及其 `_qa/*_grayscale.png`，在论文预计显示尺寸下逐项检查：中文、负号、希腊字母是否缺字；标题和坐标是否裁切；刻度、标注和图例是否重叠；颜色与灰度是否可区分；数据点、误差棒和边界是否被坐标范围截断；多面板编号、间距和跨图语义是否一致。
4. 发现问题必须回到绘图代码修正，重新运行、重新审计并再次打开预览；不得直接在 PNG 上涂改。
5. 自动审计只证明文件层面的条件通过，不能代替对数据、统计含义和最终视觉效果的检查。
